## `> now building`

### 🧠 [Local AI Workstation](https://github.com/Carlsmeister/local-ai-workstation)
Upload a CV, get it analysed by a team of local AI agents. **Nothing leaves your machine.**

- **Ingestion:** PDF/DOCX parsing with Apache Tika, chunking and embeddings into PostgreSQL pgvector
- **Multi-agent workflow:** ATS, keyword, recruiter and validation agents behind one orchestrator
- **Guardrails:** factual-integrity checks, PII masking, prompt-injection test fixtures
- **Also:** job-ad matching, section rewrites, React + TypeScript dashboard

`Spring Boot` `Spring AI` `Ollama` `pgvector` `React` `TypeScript` `Docker`
